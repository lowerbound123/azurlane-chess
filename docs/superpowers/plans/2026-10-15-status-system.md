# 状态系统一期实施计划

用户已批准实施。基线 v0.6.4。舰船与飞机共用状态底层，正常玩法暂不自动施加状态。

## 工作与验收
- [x] 共享核心：定义/实例、同源刷新、异源取强、有限叠层、期限、派生属性、周期效果。
- [x] 战斗：移动/视野/伤害统一入口、规划/AI/服务端一致、周期伤害后治疗及死亡清理。
- [x] 数据：普通/教学存档、网络过滤、契约、Worker、回放快照及回合。
- [x] UI：名称上方6px图标/8px命中区（用户后续要求缩至1/3），4个+溢出，150ms Tooltip，视野与交互隔离，开发预览。
- [x] 验证：旧确定性基线、状态单测/集成测试、真实浏览器桌面与触屏、类型检查、完整测试、构建，版本只递增一次。

## 约定
- 基础 cfg 不可被临时状态覆盖；正常单位无状态时不输出额外字段。
- 规划时施加当轮生效，执行中施加下轮生效。持续两轮从R5开始则R5、R6结算。
- 周期伤害→存活者治疗→死亡/母舰清理→占点/胜负→回放快照→到期移除。
- 来源消失不清除状态；飞机回收或击落清除，不跨出击。
- 主炮/鱼雷/布雷保存输出伤害快照；受击时读取承伤修正。飞机不继承母舰状态。
- 隐藏来源不能进入公开视图；回放与当前游戏状态独立。
- 不迁移烟幕/雷达/封锁/护航，不新增正式技能/触发概率/舰种状态。
