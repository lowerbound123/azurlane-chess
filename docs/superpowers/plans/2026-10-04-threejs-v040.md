## Interfaces
`BattleMap3D` named export in `src/battle-map-3d.js`, prop `model`.
Model: `cells:[{q,r,k,known,visible,island,deploy,overlay,tutorial,hovered}]`, `ships` (filtered engine ship objects plus tutorial boolean), `planes` (filtered plus angle degrees), `torpedoes`, `mines`, `selected`, `phase`, `mode`, `previews` (existing main previews), `mainTargets`, `rays`, `showPlans`, `showRanges`, `overlayType`, `airRange:{origin:{q,r},radius}` or null, `visuals:{projectiles,effects}`, `busy`.
Methods reset(), focus({x,y}) in ENGINE coordinates, zoomBy(factor), toggleRotate(); emits zoom(number), rotate(boolean), hex({hex,event,forceMove}), ship({ship,event}), node({index,shipId}), hover(hex), home().
Visual projectiles: `{id,kind,team,position:{x,y,z},trail:[{x,y,z}]}` where y is height and z is engine y; null position allowed for clipped particle but visible trail. Effects `{id,kind,at:{q,r},age,text}` normalized age0..1. `sampleBattleVisuals(events,time,visible)` filters positions/trails by visible hex and returns above. `resolveRound` adds `presentation` event array; gameplay output unchanged. `interpolateFrame` interpolates `t` only in addition to existing unit positions. main calls sampler with `finished.presentation, playFrame.t, visible`.
