## 下载流程和清单

- `audio.music` 保留原战斗曲配置；`audio.musicLibrary` 列出新增曲目的名称、建议用途和精确官方包路径。名称／用途不使转码指纹失效。
- 通用曲目 key 为 `music:<id>`，独立保存到 `assets/battle-audio/music/<id>`；相同 Cue 名不会互相覆盖。
- 全部 BGM 的扩展名为 `.webm`、编码为 `opus`，音乐参数独立记录在 `musicProcessing`。语音／音效的指纹、505 个文件及 42 个清单条目逐项不变。
- 输出 `sampleRate`／`numSamples` 记录编码后的实际数据，样本数按 FFprobe 解码帧的 `nb_samples` 累计；`sourceSampleRate`／`sourceNumSamples` 保留 ACB 源信息。
- 对应旧 BGM 的 7 个 M4A 在新文件与完整清单校验通过后才删除；当前没有重复文件、缺失文件、路径碰撞或未登记音频。
- 精确源包大小／MD5、ACB 引用、AWB ID、HCA 全帧校验及有效窗口验证保持。旧候选的 HTTP 404 与样本窗口不符均明确拒绝，未放宽校验。
