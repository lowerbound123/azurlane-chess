# v0.6.3 对象存储与固定资源验收

本批从 v0.6.2 推进至 v0.6.3，版本脚本仅运行一次。默认本地资源，远程读取适配 S3、OSS 和 COS；资源由部署者手动上传。

## 自动验证

- `npm test`：93 个测试文件、510 项测试全部通过。
- `npm run typecheck`：前后端类型检查通过。
- `npm run build`：前端和 Node 服务构建通过；连续两次构建后，`assets/runtime` 内全部 14 个文件（含清单）的 SHA-256 和修改时间保持不变。
- `npm run assets:spine`：显式导出固定缩略图、生成发布资源及校验复制成功。普通构建不调用导出器。
- 缺失/过期/损坏素材、清单分组及依赖覆盖不全会阻止准备，并提示对应生成命令。
- 100 个并发请求首次解析同一资源只签发一次；有效期内复用，到期并发请求只再签发一次。签发失败不缓存，后续可恢复。
- 官方 AWS SDK v3、OSS V4、COS SDK 使用假凭据生成签名通过，并验证自定义域名在签名时配置。编译后的 Node 25 服务加载 SDK 通过。
- 回归覆盖旧服务、本地默认、批量解析、图片变体、Spine 多贴图、整组回退、GLB 损坏字节、私有配置开发访问拦截。

## 真实浏览器与本地桶替身

使用生产构建、实际后端签名接口、本地 HTTP 桶替身和 Chrome，未连接真实云桶。

- 两个独立浏览器会话访问编队及部署画面：签发次数保持 12，第二个会话的 12 个资源全部命中共享缓存。
- 桶返回 404、403 时，图片、缩略图、Spine 骨架/图集/贴图和 GLB 均回退同版本本地文件，部署画面正常。
- 桶对 GLB 返回 HTTP 200 的无效内容时，校验失败后使用本地模型，错误字节不进入成功缓存。
- 完成全部故障场景及手机访问后，签发次数仍为 12、缓存命中 86；没有由下载失败触发重复签发。
- 桌面 1440×1050、手机 390×844 均完成资源加载；无 JavaScript 运行异常，无水平页面溢出。选船页面未创建缩略图截图 canvas 或 blob 图片。
- `/game/` 子路径额外构建通过纯静态（配置接口 404）及旧服务（配置缺少资源模式字段）检查：八个实际加载的图片/缩略图/Spine/GLB 文件均从子路径返回 200，画面正常，无 JavaScript 运行异常。

## 审查与验收边界

独立审查发现的四项问题均已修复并复查：Vite 私有配置暴露、清单必需项遗漏、损坏 GLB 缓存、未绑定舰船的角色导出遗漏。复查未发现遗留 P1/P2。

真实 OSS/S3/COS 的对象权限、CORS、绑定域名和下载仍需有效配置后验收。当前证据是官方 SDK 假凭据签名及本地桶模拟，不代表真实云验证。未上传资源、提交、推送或部署。

资源维护、上传路径和配置示例见 [资源存储文档](../ASSET-STORAGE.md)。
