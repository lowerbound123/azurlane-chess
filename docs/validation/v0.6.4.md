# v0.6.4 固定资源同步脚本验收

新增独立 `npm run assets:sync` 命令，复用既有资源清单和私有存储配置；`--dry-run` 仅校验及输出本地计划。上传前查询元数据，跳过相同对象，不删除桶内旧文件。上传身份可通过既有密钥环境变量覆盖。

- 相关回归：4 个测试文件、21 项测试通过，包括既有签名解析和私有配置行为。
- 官方 S3、OSS、COS SDK 使用假凭据对本机 HTTP 桶替身执行实际 HEAD/PUT，文件字节、SHA-256 元数据、Content-Type、Cache-Control、404 和 403 分支通过。
- 真实 Node 25 CLI 使用当前资源清单：预览零网络请求；首次上传 13 个唯一文件；再次全部跳过；403 时无写入且退出码为 1；输出不包含测试密钥或签名 URL。
- 同步流程回归覆盖路径去重、冲突和非法路径拒绝、前缀与读取端一致、并发上限、素材变更检查、失败继续及 SDK 客户端释放。
- 前后端类型检查及生产构建通过（仅既有大分块提示）。版本脚本只执行一次，从 v0.6.3 推进至 v0.6.4。

本批没有修改游戏交互，无需重复浏览器画面验收。真实云桶上传仍需有效配置和写入权限后验证；本地桶替身不代表真实云验证。未提交、推送或部署。

用法及权限要求见 [资源存储说明](../ASSET-STORAGE.md)。
