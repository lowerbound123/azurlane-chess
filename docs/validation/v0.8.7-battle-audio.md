正式文件和具名 Cue 清单位于 `assets/battle-audio`。当前配置 50 艘中的另外 9 个未引用候选没有下载；未获取完整角色主界面语音、gift 包、其他音效包或音乐全集。

解密按 [Perfare 原文](https://www.perfare.net/archives/816) 的公开参数实现，密码表参考固定提交的 [Nyagamon/HCADecoder](https://github.com/Nyagamon/HCADecoder/tree/e26b4d3a8bb450224ede3527d522c0330f7bf02b)，保留 MIT 许可证。真实短样本的解密输出 SHA-256 与原版 `clHCA::Decrypt()` 相同。

HCA 的编码延迟及尾部填充已准确去除。窗口采用 `[delay, blocks × 1024 − padding)`，严格验证窗口长度等于 ACB 样本数，并将音频时间戳归零。最终清单的处理版本为 revision 2。

## 验证结果

- 官方索引和全部 43 个原始包：大小与 MD5 校验通过，原始包缓存供增量修复。
- 全部 506 个 Cue：源包解析出的名字、AWB 文件 ID、声道、采样率、有效样本数和 Cue 时长与清单一致。独立审查重新读取并核对了全部源包。
- 全部 HCA：头部及每个帧的校验和通过；源格式头的 `blocks × 1024 − delay − padding` 与 ACB 的有效样本数一致。
- 全部 M4A：转码时逐条 FFprobe 验证 AAC 编码、时长、采样率和声道；最终再次完整解码，0 错误、0 静音文件，RMS 范围约 −33.32 至 −9.40 dB。
- 清单与物理目录完全对应：506 个登记文件、506 个实际文件，无缺失或未登记音频。
- `npm run assets:check`：41 套舰娘美术和 43 组战斗音频全部通过离线校验。
- 在 `FFMPEG_BINARY`、`FFPROBE_BINARY` 指向不存在路径的条件下运行完整 `npm run assets:fetch`：美术与音频均返回 `planned: []`、`changed: false`，不调用外部解包／转码流程、不联网、不改写已完成资源。
- Python `unittest discover -s scripts/ship-assets -p 'test_*.py'`：20 项通过。
- 最终 `npm test`：145 个文件、794 项通过，118.03 秒，退出码 0。
- 最终 `npm run typecheck`：前后端类型检查通过，退出码 0。
- 最终 `npm run build`：前端和服务器构建通过，退出码 0。Vite 保留既有大 chunk 提示。
- `git diff --check` 通过。

定向测试包括精确下载范围、UTF／AWB 边界、独立解密样本、编码窗口、原始包校验、重复执行无下载／无改写、单包损坏修复、无效转码不覆盖既有文件、损坏清单元数据修复、特殊 Cue 名、旧处理版本记录更新，以及现有舰娘资源入口集成。独立审查提出的问题均已完成复现、修复与复核，无遗留问题。
