## 下载脚本与清单

- 现有 `npm run assets:fetch` 和 `--audio-only` 入口统一产出 `.webm`，无需额外下载命令。
- Node 校验和产物发布统一检查 WebM 头、Opus 编码标记、48 kHz、时长／样本数、文件大小与 SHA-256；源包继续核对大小与 MD5。
- `voiceProcessing`／`effectsProcessing`／`musicProcessing` 分别记录 32／64／80 kbit/s 编码设置；顶层 `processing` 更新为统一 Opus／WebM 的 revision 3 摘要。
- 各类设置独立参与处理指纹，旧 BGM 的指纹基础保持兼容。实际首次计划严格为 41 组舰船语音和 1 组音效，共 42 包；7 首 BGM 的文件和完整清单条目逐项不变。
- FFmpeg 先按 HCA 编码延迟、尾部填充与 ACB 样本数裁切，再重采样并编码。所有类型按 FFprobe 实际帧的 `nb_samples` 累计输出样本数，保留 `sourceSampleRate`／`sourceNumSamples`。
- 只有新文件和完整清单全部校验通过后，才清理每条新 WebM 对应的已知 M4A 前身；此次已清理 505 个旧语音／音效 M4A。
