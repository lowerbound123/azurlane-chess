# 独立爆炸特效

三套 Three.js 特效已接入正式炮击、鱼雷和航空炸弹命中。独立预览保留用于观察；战斗通过事件年龄压缩播放时长，不改变伤害数值。

| 特效 | 时长 | 主要表现 | 峰值观察时间 |
| --- | --- | --- | --- |
| 火炮命中 | 1.8 秒 | 短促亮核、小火团、放射火星与金属碎片，随后少量烟尘 | 0.24 秒 |
| 鱼雷命中 | 3.0 秒 | 高耸白色水柱、连续喷流、抛物线水滴、落水雾气与扩散泡沫 | 0.64 秒 |
| 飞机轰炸 | 3.6 秒 | 更大的分层火球、延迟升起的烟团、余烬和周围水雾 | 0.52 秒 |

这里的时间是视觉制作参数，不代表武器伤害、攻击范围或实际物理尺度。飞机轰炸展示单枚炸弹命中的效果。

## 预览

启动 `npm run dev -- --port 4175`，打开 `/tools/explosion-preview.html`。预览入口只在开发环境挂载，不加入正式应用路由。

- 三种效果并排播放；窄屏纵向排列。
- 暂停、重新播放、循环、1× / 0.5× / 0.25× 速度。
- 拖动 0—4 秒时间轴，回看任意时刻。
- “峰值对照”将三种效果各自停在推荐观察时刻，因此此模式不是同一时间点。
- 桌面拖动旋转、滚轮缩放，以及斜视/俯视切换。触屏保留页面纵向滚动。
- 系统减少动态效果偏好启用时，默认停在峰值对照。

## 文件和使用方式

- `src/scene/vfx/explosions.ts`：确定性粒子、喷流、水面波纹及三个效果预设。
- `src/dev/ExplosionPreview.vue`：独立观察场景与播放控制。
- `tools/explosion-preview.html` / `.ts`：开发入口。
- `tests/explosion-study.test.ts`：回看、结束、随机种子与资源释放验证。

```ts
const effect = new ExplosionStudy('torpedo', 19);
scene.add(effect.root);
effect.seek(0.64); // 从起爆开始的绝对秒数，允许向前或向后跳转
// 不再使用时：
effect.dispose();
```

原点是命中点，Y 向上；效果实例本身不开动画循环。调用方传入绝对时间，暂停、拖动和重新播放不会重建粒子，也不会累计模拟误差。相同种子保持相同粒子分布。时间小于零、非有限或达到时长时，根节点隐藏。

粒子使用 GPU 实例化平面和程序化着色器；水柱为沿抛物线展开的分段带，水面为程序化波纹。火焰、烟、喷雾分别有轮廓噪声、柔边和生命周期透明度。没有外部贴图依赖。预览用单个 WebGL renderer 和共享相机分区绘制三个场景，卸载时释放几何、材质、控制器与动画循环。

实际接入与回放约定见 `docs/art/ABILITY-STUDIES.md`。
